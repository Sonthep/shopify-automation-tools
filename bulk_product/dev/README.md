# dev/ — Debug & Test Scripts

โฟลเดอร์นี้เก็บ scripts ที่ใช้สำหรับ debug และ test เท่านั้น — **ไม่ใช้ใน production**

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `debug_bulk_result.py` | ดู result จาก bulk operation |
| `debug_check2.py` | ตรวจสอบข้อมูลเพิ่มเติม |
| `debug_check_metafield.py` | ตรวจสอบ metafield values |
| `debug_direct_update.py` | ทดสอบ update โดยตรง |
| `debug_inv.py` | ตรวจสอบ inventory |
| `debug_schema.py` | ดู GraphQL schema |
| `test_query.py` | ทดสอบ GraphQL queries |
